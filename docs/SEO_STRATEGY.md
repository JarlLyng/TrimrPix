# TrimrPix SEO Strategy

## 1. Goal

Drive organic traffic from Mac users who need to compress and optimize images.

Primary conversion goal:
- Download TrimrPix from the Mac App Store

Secondary goals:
- Capture comparison traffic (ImageOptim alternatives, TinyPNG alternatives)
- Capture workflow traffic (compress images for web, optimize photos for email)
- Attract indie developers preparing App Store assets

---

## 2. Core Positioning

TrimrPix should position itself as:

**"The fastest, simplest image optimizer for Mac. Drag, drop, done."**

Target audiences (broad to narrow):

1. **Mac users** who need smaller image files (largest group)
2. **Web developers and designers** optimizing assets for performance
3. **Bloggers and content creators** compressing images before upload
4. **Indie developers** preparing App Store screenshots and assets

Key differentiators:
- Fully offline (privacy-first)
- One-time purchase (no subscription)
- Native Mac app (fast, no Electron)
- Supports JPEG, PNG, GIF, WebP, AVIF

## 12. AI Search Optimization (GEO)

AI systems (ChatGPT, Google AI Overviews, Perplexity, Gemini) increasingly answer user questions directly.

To increase the chance of TrimrPix being cited:

- Answer the question immediately at the top of each page
- Use clear headings and structured content
- Use tables for comparisons and specifications
- Avoid long introductions before the answer
- Include specific numbers (e.g., "reduce size by up to 80%")

Example for image formats page:

> **JPEG vs PNG: which should I use?**
> Use JPEG for photos and images with many colors. Use PNG for graphics, logos, and images with transparency. Use WebP for the best balance of quality and file size.
