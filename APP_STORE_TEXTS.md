## Description (App Store listing)

```
TrimrPix shrinks image file sizes on your Mac without visible quality loss. Drag, drop, optimize, and save space — fast, private, and fully offline.

SUPPORTED FORMATS
• JPEG — lossy compression with adjustable quality
• PNG — lossless optimization with alpha channel stripping
• GIF — validation and pass-through
• WebP — modern web format, 25-35% smaller than JPEG
• AVIF — next-generation compression with best-in-class savings
• HEIC — Apple's default photo format from iPhone/iPad

KEY FEATURES
• Reduce file sizes by up to 80%
• Drag & drop — add images instantly
• Batch processing — optimize hundreds of images at once
• Watch Folder — auto-optimize new images added to a folder
• Quality presets — Low (60%), Medium (80%), High (95%), or Custom
• Fully offline — no uploads, no cloud, no account required
• One-time purchase — no subscription, no in-app purchases

PERFECT FOR
• Web developers optimizing site assets
• Bloggers compressing images before upload
• Photographers reducing file sizes for sharing
• App developers optimizing App Store screenshots
• Anyone who wants smaller images without quality loss

All processing happens locally on your Mac. Your images never leave your device.

Requires macOS 15.2 or later.
```
